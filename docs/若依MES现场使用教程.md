# 聚星数据平台-制造MES 现场使用教程

适用版本：若依 Java MES 1.1.x。PC 管理端、工位端和 TV 端使用同一套后端数据；工位和 TV 不是管理后台的缩小版。

## 1. 地址与角色

| 端 | 用途 | 是否登录 |
|---|---|---|
| PC 管理端 | 配置基础资料、工单、SOP、设备、报表和运维 | 必须登录 |
| 工位端 | 现场扫码、查看 SOP、接收消息和测试结果 | 可直接进入；第一次实际扫码时登录，成功后本机自动恢复 |
| TV 大屏 | 只读查看生产状态 | 不登录 |

开发预览地址为：管理端 `http://服务器:5174`、工位端 `http://服务器:5173/station`、TV `http://服务器:5173/tv`。正式部署时应由 Java 服务使用同一端口提供 `/admin/`、`/station`、`/tv`，不能让生产现场依赖 Node.js 开发服务器。

管理员在安装或初始化时设置。不要使用演示密码，也不要把密码交给工位或仪器。

## 2. 上线前一次性配置

按此顺序建立一条试产线，避免工位出现“无可用工单/批次”。

1. 以管理员身份登录，进入“资源与协同”，建立车间、产线、产品、五道工序及对应工位。
2. 进入“生产运营 → 生产工单”，建立工单，选择产线和产品，设置计划数量；再建立批次。各批次计划之和不得超过工单计划。
3. 建立操作员和审核员，为其分配角色；在“工位授权”中给操作员授权实际工位和数据范围。
4. 在“条码规则”分别发布主码、电芯、SN、包装码的前缀、总长度和字符类型。长度达到后，工位端自动提交；总长度包含前缀。
5. 在“SOP 作业指导书”按工序创建草稿，上传图片、PDF 或视频，设置排序和停留时间。创建人不能审核自己的版本，必须由另一名审核员审核并发布。
6. 在“设备与测试仪”登记测试设备、绑定仪器测试工位，保存仅显示一次的设备密钥。仪器只使用设备密钥，不使用管理员账号。
7. 将测试仪的通用 HTTP 地址、设备编号、密钥和测试项目映射配置给厂家或调试人员。没有厂家协议文档时，不配置或猜测 HQAPI 子路径。

## 3. 五道工序实际操作

工位端打开后先设置服务端地址并验证连接。可以先浏览页面；首次正式扫码才弹出账号密码框。登录成功后选择已授权的工位、工单和批次。下次启动会尝试恢复该终端的已认证会话；账号停用、密码变更、主动退出或清除应用数据后需再次登录。

### 主码过站

选择“主码过站”工位后直接扫主码。达到条码规则长度会自动提交；成功后建立产品生产记录、关联工单、批次、产线和 SOP 版本。

### 电芯绑定

同一个输入框先扫主码，页面切换为“等待电芯码”；继续扫电芯码即保存关联。重复绑定、条码不合规和跨工单均会被拒绝并报警。

### 仪器测试

测试平板不提供手动扫码和启动测试按钮。产品接入仪器后，由仪器按已配置 API 上传工艺检查和测试结果。后台验证主码、电芯绑定、当前工单、设备、工位和前序状态。

- FAIL 保存完整测试记录、参数和原始报文，但不会放行 SN。
- 同一上传记录重试只保存一次；内容变化的重传被拒绝并记入接收日志。
- 复测新增测试任务和结果，不覆盖旧 FAIL；最新有效结果 PASS 才可进入 SN 绑定。

### SN 绑定和包装绑定

SN 工位先扫主码，再扫成品 SN。包装工位先扫 SN，系统展示前段履历，再扫包装码完成关联。包装码重复、测试未通过、未完成前序都会被服务端拦截。

## 4. SOP、消息和异常处理

- SOP 图片和 PDF 按停留时间自动切换；视频播放结束再切下一份。可暂停、上一份、下一份，扫码不会让 SOP 从头播放。
- 重要消息在工位端消息抽屉中确认；不会再以大块页面遮挡扫码工作区。
- 红色/报警提示表示未写入生产数据，先按提示纠正，不要反复扫同一条码。
- 断网时工位端禁止过站，可继续查看已缓存 SOP；网络恢复后重新扫描，系统通过请求编号防止重复计数。

## 5. 查询、报表与 TV

“产品追溯”可按主码、电芯码、SN 或包装码查看工单、批次、全部过站、SOP 快照、FAIL/PASS/复测和测试参数。“接口接收日志”用于排查仪器认证、参数完整性、重复上传和未关联主码。

导出前必须选择具体工单和批次。产品、过站、测试明细会创建后台任务；测试导出保留 FAIL、PASS、复测与详细参数，并遵守当前筛选范围。

TV 打开后选择车间或产线、点击全屏。页面只读显示工单进度、产量、良率、在线工位、异常及最新测试结果；显示断线状态和最后更新时间，重连后自动刷新。

## 6. 管理员日常运维

1. 在“数据库备份与恢复”配置保留策略，并将备份复制到独立介质。
2. 恢复前先查看范围并输入系统显示的确认文字。恢复过程会阻止写入，自动备份当前状态，恢复后校验附件一致性并注销会话。
3. “测试业务数据清理”只允许清理明确标记的测试工单，预览范围并二次确认后执行；它不会清理客户生产历史。
4. “数据库监控”只读展示真实 PostgreSQL 状态，不提供任意 SQL 执行。
5. 在“平台外观”上传 Logo、设置名称后，PC、工位和 TV 会经实时通知同步更新。

## 7. 现场交接检查表

- [ ] 每个扫码工位使用授权操作员完成一次流程。
- [ ] 用 FAIL 测试确认 SN 被拦截；再复测 PASS 后确认可以继续。
- [ ] 确认仪器重传不重复生成结果和数量。
- [ ] 确认仪器断网、扫码枪 Enter/Tab、重复扫码报警。
- [ ] 确认 SOP 图片、PDF、视频能在目标 Android WebView 播放。
- [ ] 确认 TV 长时间运行、断线重连和全屏。
- [ ] 完成一次备份、下载、隔离环境恢复演练。

真实仪器协议和实体设备验收必须由现场实测签字；通用模拟器结果不能替代。
