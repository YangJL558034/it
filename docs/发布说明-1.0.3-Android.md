# Android 1.0.3 白屏修复记录

2026-10-16。仅更新工位 APK 和 TV APK，服务器 API 沿用现有 1.0.2 版本。本修复不代表若依 Java 迁移完成。

旧版 1.0.2 在 Android 11 / System WebView 83 上实际安装后白屏。检查发现工位 SOP 组件在应用启动时加载 PDF.js 6，其顶层代码引用该 WebView 没有的 `Iterator` 全局对象，页面无法挂载。1.0.3 将 PDF 库从启动路径移除：Android 使用系统 PdfRenderer，浏览器仅在打开 PDF 时加载 PDF.js legacy 构建；应用还加入兼容打包、首次加载的固定工位/TV 入口及可见的启动错误页。

工位包 `juxing-mes-station-1.0.3-release.apk`，TV 包 `juxing-mes-tv-1.0.3-release.apk`，均为 versionCode 4、Android 最低 SDK 24，沿用原包名和签名。实测旧包覆盖升级成功。Android 11 模拟器内分别完成安装、启动；配置 `10.0.2.2:5080` 后，工位显示免登录扫码页，TV 显示从本机开发数据库获取的实时看板。两包 v2 签名校验通过。

Android 7 模拟器自带 WebView 52，不满足 Capacitor 7 要求；两包均从白屏改为清楚显示“需要更新系统网页组件”，要求 WebView / Chrome 60 或更新。Android 系统版本满足最低安装条件并不等于网页组件已满足运行条件。Android 7 + 更新后 WebView 60 以上尚无现成测试设备，必须现场验证后才能标记通过。

本机模拟器测试尚未覆盖实体扫码枪、SOP PDF 和视频播放、遥控器、长时间运行、厂家仪器及 Windows Server 安装。提供给现场的 1.0.3 APK 应直接覆盖安装，保留服务器配置和已授权终端数据；现场先检查 WebView 版本，并用实际设备完成验收。
