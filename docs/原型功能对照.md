# 原型与正式实现对照（2026-10-16）

原型 `dist` 和用户截图是设计依据；原型的浏览器演示数据不能作为真实业务验收。以下将“后台已实现”和“交互已还原”分开记录。

| 模块 | 当前真实实现 | 差距与处理 |
|---|---|---|
| PC 导航 | 官方若依 Vue 3、三个 MES 分组、17 项功能导航与迁移状态、真实 Java 主数据和服务端若依权限 | 已选完整 Java 方案；基础资料接入完成，SOP/仪器/追溯等尚待迁移，不能把菜单存在视为业务完成 |
| 工位扫码 | 单输入、配置长度自动提交、五工序服务器校验、重复不计数 | 本次移除空闲时“重新扫描”按钮，自动恢复焦点；重复和操作失败红色提示及警报；消息移入侧边抽屉 |
| 工位登录 | 服务器验证用户，持久终端凭据，退出/停用/改密撤销 | 按用户确认，工位密码错误不限制次数、不锁定；PC 登录保留原限制；设备需实测声音与扫码枪 |
| SOP 数据与播放 | 工序外键、多文件、图片/PDF/视频、顺序/停留、另一人审核、发布归档、离线缓存、过站版本快照 | 过去所有版本纵向堆叠，未还原原型库/预览结构；本次整理为指导书库和选中版本详情。草稿先创建再上传，尚无原型的上传前整批编排/草稿文件删除交互 |
| 工单/批次 | 真实增改删、关联保护、历史保留、计划量、批次量 | 不是排产甘特图；尚未实现原型中的独立排产日历/拖拽排程 |
| 仪器接口 | 通用 HTTP、独立协议接口、任务校验、设备密钥、接收日志、异常、原始报文、模拟器 | 厂家文档未提供；不能启用猜测的 HQAPI 子路径，不能声称接通真实仪器。页面需要按原型将协议说明与接收日志整理到独立 MES 模块 |
| 测试与追溯 | PASS/FAIL/复测全部保留，最新有效测试控制后续放行，条码映射追溯 | 详情部分仍有技术字段/ID；待若依 MES 页面用名称、工序时间线与参数表完整展示 |
| 报表 | 具体工单+批次、当前筛选导出、全部测试参数、异步导出审计 | 保留真实范围校验，不采用原型全量浏览器导出 |
| 设备与消息 | 工位绑定、设备认证、心跳、重要消息确认 | 工位消息现在收纳；后台消息和设备表需继续统一专用页面 |
| TV | 独立免登录只读、实际五工序、真实曲线/进度/测试/在线状态、断线重连 | 本次使用 ECharts；显示器/Android TV 真机长时间运行尚需实测 |
| 备份恢复 | PostgreSQL+附件+配置、定时、保留、日志、恢复前备份/维护/核验 | Windows 干净机器完整安装/升级/故障恢复仍需现场验收 |
| 原型其他菜单 | 产品、产线工位、包装映射、测试异常已有 | BOM/物料库存、正式仓储出入库、维修审批流、班次排程不是当前已完成业务；不能用菜单或生成 CRUD 冒充 |

当前开发库存在自动化验收生成的订单、通知和 SOP 文件（如 `UI TEST SOP`、1 像素图片）；它们不是客户生产 SOP。不会静默删除历史或把测试文件作为正式指导书交付。验收时应上传真实工艺文件并由质量人员审核发布。

界面后续按原型的分组、留白、工序库/详情、设备接口/日志等结构还原，业务以用户确认的五道工序为准。每个页面须同时验收真实 API、权限、失败提示及交互；截图通过不代表工艺闭环通过。
