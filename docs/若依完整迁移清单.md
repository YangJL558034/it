## 固定上游与部署决策

- 官方后端 RuoYi-Vue 3.9.2，springboot3 提交 `a51a838b71b446ea27256900efe7ed2faa2a02fd`；该提交声明 Spring Boot 3.5.16、Java 17。依赖是否全部可获取以实际 Maven 构建为准，不静默改用其他分支。
- 官方 Vue 3 前端提交 `838965c5a18d2c61b73ec30c6e288057aaa08b63`。完整源码及 MIT 许可复制到 `admin-web`；Java 源码在 `ruoyi-server`。
- PostgreSQL 保留，不把历史 UUID/关联表变成名称拼接；若依系统表及 MyBatis SQL 需 PostgreSQL 方言适配。现有 MES 表、外键和历史保留，账号映射到 `sys_user`，登录/权限只由若依服务执行。
- Java 以 JAR + 随包 x64 JRE + Windows 服务托管部署；不使用旧 .NET 服务承载 Java 业务。数据库版本以 Server 2016 官方兼容清单为边界（PostgreSQL 15 候选）；新版本数据库不强行降级原数据目录。
- Redis 是若依登录/验证码/会话依赖。官方 Redis 没有通用原生 Windows 生产安装包；正在验证 Windows 可部署的兼容组件或外部 Redis 方案，不能将开发专用端口未经验证标作生产组件。
- 当前实机 Windows 11 x64。Server 2016、2019、2022、2025 和 Windows 10 的兼容性需分别记录“依赖支持”和“实际安装测试”，不能把一台机器测试概括为全部 Windows 版本通过。

- 若依系统表、日期筛选、部门祖先查询、菜单、公告、角色 Boolean 字段完成 PostgreSQL 适配。代码生成器保留源码，但不装入服务运行依赖；不能使用尚未适配的 MySQL 生成器替代 MES 业务。

### 本机预览入口与 APK 连接核对（2026-10-16）

- 若依 PC 预览为 `http://127.0.0.1:5174/login`，账号 `admin`，密码取 `.local/ruoyi/development.json` 的 `adminPassword`。本次已实际登录和退出验证，返回均为 200。安装版原 MES 的账户不等于这个独立开发库的账户。
- 开发服务可运行 `./scripts/start-dev.ps1 -ListenAddress 0.0.0.0 -AdminPreviewUrl http://127.0.0.1:5174/login`。仅 Development 模式的根路径及 `/pc` 转向若依；工位、TV 和 API 路径不转向。已验证根路径 302、局域网地址健康检查 200，默认不传参数仍是回环监听。
- 现场 APK 1.0.3 连接服务器基础地址，不能填写若依 Vite 的 5174 端口。当前机器另外存在 Windows 服务版 1.0.2，监听 8080，并已有该端口的入站规则。本次 Android 11 模拟器的工位和 TV APK 都通过本机局域网 IPv4:8080 连接成功；安装版当前无生产工单，看板为空属于真实数据状态。没有改动安装版数据库、账户或服务配置。
- 模拟器能访问局域网地址不能代替实体平板/电视到服务器的网络验收；实体设备须能互通同一局域网，并使用安装向导设置的账户。开发服务器绑定地址与端口开放是两项独立配置。
