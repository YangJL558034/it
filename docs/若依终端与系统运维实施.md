# 终端、统一标识与运维迁移设计

2026-10-16。承接 MES 主数据阶段，当前尚未交付全部功能。本文件先记录实现范围，测试后逐项更新，不能凭菜单或设计标记完成。

## 工程与关系

- Java `ruoyi-mes`：branding（统一标识）、terminal（若依用户的工位会话）、production（五工序与追溯）、instrument（设备协议）、sop、maintenance（备份/恢复/测试数据清理）、monitor（PostgreSQL 状态）。都复用若依用户、角色、菜单与操作日志。
- `mes_branding` 保存名称、Logo 内容标识及版本；图片在独立数据目录，默认 Logo 使用用户提供的第二张图片。各端读取同一公开标识接口；只广播不含业务数据的更新通知。
- 工位凭证关联 `sys_user`，加密保存在 APK，服务端仅保存随机凭证摘要、账号状态及权限版本。工位密码错误不锁定，PC 原认证策略保留；没有另一套用户名/密码。
- `mes_unit` → `mes_batch` → `mes_work_order` → 产线/产品；过站关联产品、工位、工序、若依用户、SOP 与条码版本。测试任务关联设备、工位、产品与批次，复测增加任务/结果；上传记录唯一。生产历史仍需完整迁移，不能视为已随主数据复制。
- 原生通知改用 Java WebSocket，工位及 TV 保留现有布局；通知只触发带权限的重新取数。网络断开禁止过站。
- 备份档案包括真实 pg_dump、业务附件、SOP、Logo 和必要配置清单。运维任务日志位于数据目录，避免数据库恢复覆盖执行中的恢复日志。

## API 与端口

- `/api/branding`、`/api/branding/logo/{hash}`：公开品牌配置与图片；`/mes/branding` 管理端上传，仅持有编辑权限的用户可修改。
- `/api/health`：Java/客户端版本兼容及数据库/文件检查。5174 开发代理转发 Java `/api`、`/ws`，并监听局域网；正式部署由 Java 服务提供管理静态资源、工位和 TV。不能要求现场运行 Node 开发服务器。
- `/api/auth/station/*`：工位登录、恢复、退出；`/api/station/*`、`/api/tests`、`/api/tv` 对应终端业务。仪器使用独立设备凭证。
- `/mes/maintenance/*`：后台备份任务、校验、恢复预览/确认、策略和测试工单标记/清理。恢复、清理必须验证管理员、展示范围、生成当前备份、控制写入并验证文件一致性。
- `/mes/monitor/database`：只读数据库、表、会话和连接池指标，无任意 SQL 执行入口。若依“数据监控”菜单指向真实页面。

## 清理的安全边界

用户确认“删除”指测试业务数据。只清理明确标记、明确选择的测试工单，预览包括批次、产品实例、过站、测试任务/结果/参数及相关导出。默认保留产线、工位、产品定义、用户、SOP 和设备。未标记工单拒绝清理；范围确认令牌绑定操作者、期限和当前记录摘要。不会执行现有客户工单清理来演示功能。

## 验证门槛

测试环境验证 Logo 上传越权、内容与尺寸校验、三端自动更新；若依工位登录/重启恢复/撤权、连续扫码与重复报警、并发绑定/跳站/FAIL/复测/重复上传；真实 pg_dump 与隔离恢复、恢复失败保护、附件篡改拒绝、清理范围及预备份；真实 PostgreSQL 监控和无权限拒绝。再构建两个签名 APK，实装模拟器，实体设备和 Windows 目标系统仍须实测。
