# 使用手册

## 建立第一条产线

1. 安装 Windows 服务器，在完成页打开后台，使用 admin 和安装时设置的密码登录。
2. 新建产线及车间、产品；依次创建主码过站、电芯绑定、仪器测试、SN 绑定、包装绑定五个工位，关联同一产线及对应工序。
3. 新建工单，选择产线、产品、计划数量，再建生产批次。批次计划合计不能超过工单计划。
4. 新建操作员和质量审核员。TV 只读展示不要求人员账户。使用“角色权限”配置功能权限；使用“工位授权”为操作员分配实际工位。管理员保留系统恢复权限，不能禁用自身账户。
5. 在条码规则中分别发布主码、电芯、SN、包装码的前缀、长度和字符类型。多个前缀用逗号分隔；总长度包含前缀，区分大小写。历史记录保留旧规则引用。
6. SOP 管理按工序创建草稿，上传 PNG/JPEG、PDF、MP4/WebM 多份文件，预览、调整顺序和时间。另一名有质量权限的用户审核后发布；旧版自动归档。
7. 设备登记选择测试工位、程序标准版本和全部测试项目/单位/上下限，保存一次性设备密钥。通用协议与厂家协议不同；厂家文档未确认前只做通用接口模拟验收。

## 工位操作

工位端填写如 `192.168.0.197:8080` 的服务器地址并验证连接后，可直接进入工作台，无需先登录。首次扫描主码或 SN 时弹出登录框；认证成功后选择授权工位、该产线工单和批次，加载 SOP，再自动提交刚才扫描的条码。取消登录或认证失败不会过站。也可提前点击顶部“登录”或“切换工位”。

未登录时只显示工作台入口和流程说明；工单、SOP、消息、测试结果及生产记录仍按登录权限读取。退出回到工作台，下次正式扫码重新认证。顶部设置按钮可改服务器地址，修改地址退出当前会话。测试工位登录并选择工位后仍只自动收结果，不需要人工扫码或启动。

此进入方式包含在 1.0.1 版本；旧版安装包保留供回退使用。工位页面即使用管理员登录，也不显示管理后台、工位终端和生产大屏切换按钮。

- 主码工位：扫主码自动过站。
- 电芯工位：先扫主码，再扫电芯码。
- 测试工位：由仪器扫主码、工艺检查及测试，平板只自动显示结果和历史，没有扫码框或启动按钮。
- SN 工位：先扫主码，再扫 SN；最新测试必须 PASS，且没有待完成测试任务。
- 包装工位：先扫 SN，查看自动显示的前段履历，再扫包装码。

扫码达到后台已发布规则的条码长度后自动提交，无需手动回车；主码、电芯、SN、包装分别使用对应长度。仍兼容扫码枪附加 Enter 或 Tab。所有扫码工位只有一个输入框；错误时按提示重扫。网络重试复用同一请求编号，重复上传/复测不重复计生产数量。断网不能过站，当前已缓存 SOP 可继续观看。

SOP 图片/PDF按文件停留时间切换，PDF可翻页；视频播放结束后切换。暂停、上一份、下一份不会因扫描重置。后台换版后必须加载新 SOP 才能继续过站。重要消息点击“确认收到”，后台可查看确认人和时间。

## 追溯、导出、大屏

完整追溯支持主码、电芯码、SN、包装码，查看每次过站和 SOP 版本、全部测试与参数、原报文。异常上传在“设备接收日志”中保留，拒绝记录不放行。

生产报表先选工单和批次，再填写条码或 PASS/FAIL 筛选。产品、过站、测试明细分别提交后台任务。按历史测试结果筛选产品后，测试导出仍包含这些产品全部 FAIL/PASS/复测及参数；导出任务记录操作者和筛选范围，下载为 UTF-8 CSV。

大屏直接打开 `/tv` 或 TV APK，无需登录，选择车间/产线，点击全屏。显示五工序真实数据及最后更新时间，断线自动重连和定时快照校验。TV 接口和实时通知通道只读，不授予工单、追溯、导出或生产写入权限。工厂局域网内能够访问服务器的终端可以查看大屏数据。

## 备份与恢复

管理员在“备份恢复与系统配置”设置间隔小时、保留天数，或立即创建备份。备份包含 PostgreSQL、SOP、附件、非密钥配置和摘要清单。业务配置在数据库中；目标机连接密钥保留在受保护配置目录，不被下载备份替换。备份目录须额外复制到另一块介质。

恢复先点“恢复前校验”，阅读整库与文件替换范围，输入系统显示的完整 RESTORE 确认文字。系统先备份当前状态，再维护恢复、校验附件，最后退出所有会话。失败尝试自动回滚；恢复前备份、旧文件目录和外部恢复日志保留，确认后由管理员清理。

如恢复时断电或进程崩溃，启动后维护标记会继续阻止写入。由管理员使用安装目录 `maintenance/recover-windows.ps1` 恢复已校验备份；参数示例见 Windows 安装说明。不要直接删除维护标记绕过验证。

## 当前明确边界

- 包装码为一件一码；一箱多件需扩展箱模型后再启用。
- 五工序为确认的固定路线；新增路线必须版本化，不允许回改旧历史。
- 设备标准变更建议新建设备/协议版本，不覆盖历史任务标准。
- 生产历史数据不可直接删除。已关联工单不能改产线/产品/编码；仍可安全调整计划，不能低于已分配批次数量。有待测任务时不能关闭工单。批次计划不能低于已投入产品数。
- 没有离线生产队列；断网必须恢复连接才可继续。
- 真实厂家协议、平板扫码枪、电视遥控器、持续运行和干净 Windows 安装/升级仍需现场验收。
