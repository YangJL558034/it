# 聚星数据平台-制造MES 1.0.2

2026-10-16，候选发布。

## 后台与大屏

后台重做分组导航、面包屑、概览卡、列表工具栏、搜索筛选、分页、中文状态和编辑表单。系统配置分为基础信息、自动备份策略、备份记录。业务写入与关联校验继续使用原后台接口。

TV 使用 Apache ECharts 6.1.0，深蓝监控布局包含 24 小时投入/包装趋势、最新有效测试合格率环图、工单轮播、在线工位、仪器结果、异常动态及五工序。所有统计来自实际数据库，并随产线/车间筛选变化；无测试时显示等待数据，不虚构百分比。保持匿名只读及 SignalR 实时更新。开源来源与许可证见《开源组件与界面来源》。

## 工位一次登录

首次扫描登录后，下次启动在线验证终端凭据并恢复实际用户，无需重复输入账号密码。首次选择授权工位/工单，重启时自动恢复仍有效的选择；配置失效时重新选择，正式过站仍验证权限、工序、条码、SOP 和网络。

安卓通过 Android Keystore AES-GCM 加密保存终端凭据，不保存密码；网页用 HttpOnly Cookie，访问令牌仅在内存中。短期会话过期后自动续签；退出、账号停用/修改、数据库恢复撤销持续登录。终端凭据服务端有效期为 10 年，网页 Cookie 的实际保留时间受浏览器上限和清理策略约束。清除应用数据或重装后需要重新登录。网页版请直接访问所配置服务器的 /station；跨站 HTTP Cookie 不作为支持的记住登录方式。

## 升级

先安装服务器 1.0.2，再覆盖安装工位/TV APK。Android versionCode=3，包名与原签名保持不变。安装包保留原 Windows AppId、服务 ID 和数据目录。

新增迁移 20261016010310_RememberStation：StationCredential.UserId → User；Session.StationCredentialId → StationCredential。数据库只保存终端凭据的哈希。安装器在备份后执行迁移，旧生产记录保持不变。失败时按《Windows安装交付》《版本兼容与升级》恢复匹配版本的程序、数据库与附件。

## 工位交互与若依评估

按用户明确要求，工位登录不限制密码错误次数、不因累计错误锁定。PC 后台保留原登录限制。工位自动聚焦扫码框，提交期间接收下一条输入；重复扫码显示红色提示并播放双音警报，不增加产量。重要消息移入右侧抽屉并保留真实确认记录。网页提示音需要浏览器允许音频；安卓使用原生 ToneGenerator，实体音量与扫码枪待验证。

SOP 管理整理为工序指导书库、版本筛选、选中版本预览及文件编排，状态中文显示。完整若依接入尚未实施：已完成现有栈与迁移核查、A/B 对比，推荐保留 .NET，仅接入若依 Vue 3 PC 前端。详见《若依改造评估》《原型功能对照》，未完成的原型业务明确列出。
