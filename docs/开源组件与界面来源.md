# 开源可视化与界面来源

本次 TV 使用 Apache ECharts 6.1.0（https://github.com/apache/echarts），Apache-2.0 许可证。按官方模块化方式只注册折线、环图/饼图、柱图及相关组件，图表数据来自本项目的 /api/tv，不使用模板演示数据或 CDN。

其渲染库 zrender 6.1.0 采用 BSD-3-Clause。许可证和 NOTICE 在 web/public/licenses，随 Web、APK、Windows 安装包一并交付，可通过 /licenses/echarts-LICENSE.txt 和 /licenses/echarts-NOTICE.txt 阅读。

后台布局参考 Vue Vben Admin（https://github.com/vbenjs/vue-vben-admin，MIT）的分组导航、面包屑及列表工具栏组织方式。界面由本项目自行使用 Vue 3 / Element Plus 编写，没有复制该项目组件或资源，也没有引入其整套框架。

保留既有 MES 配色方向，重做排版、信息层级、状态、分页与设置卡片。大屏采用独立深色监控布局、真实小时趋势和最新有效测试分布。图表不使用随机数填充。

PDF 预览依赖 pdfjs-dist 更新至 6.2.108，许可证同样随包提供；本次 npm 审计发现的 ECharts 和 PDF.js 已知问题通过更新修复。具体安装版本由 web/package-lock.json 锁定。
