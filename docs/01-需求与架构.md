# MES 正式系统实施基线

日期：2026-10-15。原型位于 dist/，仅作设计参照，生产入口不加载原型脚本。保留深蓝导航、青绿主色、中文表格、单入口扫码、左 SOP 右作业、独立深色大屏。原型所有本地生产数据、演示账号不迁入正式系统。

## 目录和边界

- server/Mes.Api：ASP.NET Core 10 模块化单体；Security、MasterData、Production、Instruments、Sop、Reporting、Operations；EF Core 10 / PostgreSQL。
- web：Vue 3 / TypeScript / Element Plus；PC、工位、TV 独立路由；SignalR；Capacitor Android 工程。
- simulator：通用 HTTP 仪器模拟器，不能代表厂家实机。
- deploy、scripts：部署、数据库迁移、开发环境、备份恢复。
- docs：数据关系、API、使用与验收记录。

单节点起步，不使用微服务、Redis、Kubernetes。数据库是生产状态唯一权威；文件服务保存在服务器持久目录。客户端仅持久化服务器地址及 SOP 缓存，登录凭证只在内存。

## 生产不变量

1. 主码→电芯→仪器测试→SN→包装；同一产品固定工单、批次、产线。
2. 条码按发布版本校验。主码、电芯、SN、包装全局防重（首版包装码一件一码；多人装箱需另行定义箱模型）。
3. 服务端事务与 PostgreSQL 约束保证并发绑定、重试只计一次；完成量按唯一产品/工序过站记录计算。
4. 有效测试按任务创建顺序确定；存在未完成测试任务时禁止流转，最新有效结果必须 PASS。已绑定 SN 后的新测试作为异常，不重写生产结论。
5. 测试 PASS/FAIL/复测参数和原报文均追加保存；相同设备记录编号相同内容重试幂等，不同内容拒绝。无法关联的报文保留异常接收日志，不放行。
6. 工位端只有一个扫码框，服务器维护扫码上下文；断网禁止过站。仪器测试工位无扫码框、无启动测试按钮。
7. SOP 关联工序，审核发布后不可修改内容，发布新版本归档旧版，过站快照关联版本。
8. 报表强制工单+批次，后台任务导出当前筛选范围，测试明细包括全部复测和参数。
9. 已有历史引用的主数据禁止删除、关键关联禁止修改；每项管理变更和拒绝有审计。
10. 备份包含 PostgreSQL、SOP 文件、非密钥配置和清单；恢复前预检及管理员明确确认，备份当前状态，维护期间拒绝写入。

## 权限和部署

角色：Admin（系统管理）、Supervisor（计划/生产管理）、Quality（质量/SOP/报表）、Operator（授权工位作业）、TV（只读大屏）。服务端同时检查角色及工位授权。设备凭据仅可调用设备 API，不是用户凭据。初始管理员由环境变量提供强密码，不存在固定演示密码。生产 TLS 由反向代理终止，开发绑定 loopback。

## 仪器协议待提供项

已知设备有 MES 配置，示例基础地址 http://192.168.0.233:8080/HQAPI/MES/。这不是已确认的 API 定义。待厂家提供子路径、方法、认证、用户信息字段、工单关联字段、工艺检查请求响应、结果和附件格式、超时/重试/字符编码、任务编号语义和测试标准项目列表。

建立独立协议适配模块及规范化服务：用户信息、工单关联、工艺检查、结果上传。通用接口版本为 /api/instrument/v1；厂家适配接口在文档确认前不注册、不猜测。真实设备和产线验收需要现场实测。

## 阶段门禁

按用户要求依次实施六阶段；每阶段编译并通过对应 PostgreSQL 集成检查才继续。实际证据记录 docs/验收记录.md，失败、未测项明确记录。优先完整打通一条产线，不用假接口替代缺失功能。
