# 聚星数据平台-制造MES 1.0.1

2026-10-16，候选发布，基于现有 1.0.0 工程持续升级。

- PC、工位、TV、Android 应用标签及 Windows 安装器/服务显示名称统一为“聚星数据平台-制造MES”。
- 工位直接进入，正式扫码时登录；管理员在工位页面也没有后台或跨端导航。服务器仍验证实际人员身份、工位权限和工艺状态。
- TV 页面与 APK 不需要人员登录，使用匿名只读 `/api/tv` 与 `/hubs/tv`。局域网内可访问服务器的终端能够读取大屏显示的数据；没有开放管理、追溯、报表导出、SOP 文件或生产写入接口。
- 主码、电芯、SN、包装按已发布规则的长度自动提交。输入达到完整长度且连续字符输入结束后自动处理，兼容 Enter/Tab；超长内容不截断成合法条码。规则由后台发布，客户端不写死长度。
- 工位未登录时仅用主码/SN 规则识别首次输入；取消登录清除本次临时输入，不保存离线过站队列。登录、选工位/工单并加载 SOP 后才处理首次扫码。

## 兼容与升级

服务器 1.0.1 支持工位和 TV 客户端 1.0.0、1.0.1。新客户端 1.0.1 需要服务器 1.0.1 的匿名只读接口及规则接口：**先升级服务器，再覆盖安装 APK**。

Android 包名、签名不变，versionCode 从 1 升为 2。Windows AppId、服务内部 ID、数据库连接和数据目录不改名，避免改品牌导致新装或数据丢失。显示名称已更换。

本次没有数据库结构变更，不新增迁移；原有版本化迁移继续随包保留。安装器升级仍先停止写入、备份数据库及附件，再更新和检查；失败恢复同版本整套备份。旧版 1.0.0 安装文件不覆盖，供已有版本追溯。
