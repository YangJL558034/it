# 若依 MES 基础资料与导航验收

2026-10-16，本机 Windows x64，Java 17、PostgreSQL 17.11，Java API 5081、官方 Vue 3 开发预览 5174。是开发环境记录，不是生产系统验收。

## 当前实际可用内容

若依菜单由数据库管理，三个 MES 分组包含 17 项功能。首页使用 MES 工作台，移除框架介绍、捐赠及示例更新日志。基础管理继续使用若依账号、角色、菜单、按钮权限、日志和配置。

可操作：产线、工位、产品、生产工单、生产批次。工艺路线可只读查看五道工序。其他功能为明确的迁移状态页，不能扫描过站、上传测试、发布 SOP 或导出。若依的通知公告不是已经迁完的 MES 重要消息确认功能。

本阶段业务保护包括：主外键、唯一编码、工位继承产线部门、产品和产线范围一致、工单计划与批次数量关系、历史引用删除/关键关联变更保护、未完成测试禁止关闭已导入工单、记录版本校验。批次分配通过数据库事务及互斥锁防止并发超分配。

MES 主数据是共享的部门资料。服务端沿用若依部门范围查询，已验证全部、自定义部门、本部门、本部门及下级四类范围，以及修改角色后现有会话立即生效。仅本人角色不获得共享主数据的部门范围。前端隐藏按钮以外，写入、关联选项及按 UUID 直接访问均受服务端限制；关联选项只返回该表单需要的编号和标签。
