# 1.0.2 界面与工位持续登录

## 需求与实现范围

- 后台：分组导航、清晰的字号/间距、业务概览、列表搜索、状态筛选、分页、中文状态；保留现有写入、关联保护和权限校验。系统设置拆分为基础配置、备份策略和备份记录。
- TV：采用 Apache ECharts（https://github.com/apache/echarts，Apache-2.0），参考 Vue Vben Admin（https://github.com/vbenjs/vue-vben-admin）的分组导航与卡片层级，自行实现 Vue/Element Plus 页面，不复制其业务代码。图表资源随包离线部署。
- 大屏采用深蓝/青色生产监控设计，真实展示当前范围累计指标、最近 24 小时投入/包装趋势、最新有效测试分布、五工序、工单、工位和异常；无数据展示空态，绝不生成随机数据。1080p/4K 适配，保留匿名只读、断线状态与实时更新。
- 工位首次扫码登录后记住终端，下次启动在线验证并恢复身份；退出、改服务器、停用账号、改密码/角色后失效。无网络不放行。

## 关系与 API

新增 StationCredential（UserId 外键、凭据哈希、有效期），Session 增加可空 StationCredentialId 外键。原登录兼容，新增 rememberStation/native 参数；原 8 小时访问令牌不落盘，长期凭据只用来换取访问令牌，不可直接调用生产 API。终端凭据有效期 10 年，可通过退出或管理员更新账号撤销。

POST /api/auth/station/resume：验证终端凭据和实际用户，签发短期访问会话。
POST /api/auth/station/forget：撤销终端凭据及关联访问会话。
浏览器凭据使用 HttpOnly Cookie；安卓通过本地 Capacitor 插件使用 Android Keystore AES-GCM 加密存储，禁止保存密码或把身份对象当作认证。
Cookie 端点要求自定义头 X-MES-Station-Auth，跨域仍遵循服务器 CORS 白名单。网页建议同源访问；跨站 Cookie 须 HTTPS。安卓凭据以请求体传递，沿用已配置服务器地址。

GET /api/tv 保持原字段兼容，新增小时趋势、累计计划、工单总数与工位关联字段；趋势由真实过站按 UTC 小时聚合，显示北京时间。
