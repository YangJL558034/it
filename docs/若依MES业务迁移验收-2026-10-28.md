## 已迁入 Java 业务模块

- RuoYi 用户、角色、菜单、按钮权限、操作日志和数据范围；工位认证复用若依账号校验，但密码错误次数不锁定。
- 五道工序：主码过站、电芯绑定、仪器测试、SN 绑定、包装绑定。条码规则、工单、批次、产线、工位均为数据库外键关系；所有放行判断在服务端执行。
- 设备凭证、测试任务、参数、原始报文、接收回执和复测记录。重复记录编号仅保存一次；内容变化的重传被拒绝并保留回执。
- SOP 草稿、他人审核、发布、归档、逐文件顺序/停留时间；过站保存当时的 SOP 版本快照。
- 追溯、消息及确认、后台导出任务、实际 PostgreSQL `pg_dump` 备份、文件清单校验、恢复前备份和写入保护。
- PC、工位和 TV 从同一 Java API 获取品牌配置；品牌变更通过 WebSocket 下发。工位和 TV 不出现管理后台入口。

## 历史数据迁移

主开发隔离库已导入历史资料与历史生产记录，并保留来源账本及文件摘要；导入数量：77 条产线、81 产品、5 工序、385 工位、77 工单、86 批次、80 产品单元、145 过站、46 测试结果、50 SOP 文件、2563 条历史审计记录。旧账号被禁用后保留为历史主体，未覆盖新的若依管理员密码。

历史附件已按 SHA-256 验证后复制至 Java 数据目录；旧 .NET 备份仍必须由旧版本恢复，不能混用恢复工具。

## 尚不能声明完成的现场项

1. 厂家尚未提供 HQAPI 的子路径、HTTP 方法、字段和签名规则。因此仅已交付并测试通用 HTTP 适配层及模拟器，未声称已连通真实仪器。
2. Android 7+ 实体平板和 Android TV 盒子的网络、扫码枪、WebView 与长时间运行尚需现场实测；Android 11 模拟器只作为开发验证，不能替代现场验收。
3. Java Windows 离线安装器正在重建。保留的 1.0.2 EXE 是旧 .NET 基线，不能用于本次若依 Java 生产部署。
4. Windows Server 2016/2019/2022/2025 的干净安装、升级和恢复仍需分别留档；当前开发机的通过结果不能外推为所有 Windows x64 版本通过。

## 复跑方法

```powershell
./scripts/start-ruoyi-ops-test.ps1
python tests/integration/ruoyi-operations.py
python tests/integration/ruoyi-production.py
python tests/integration/ruoyi-sop-reports.py
node tests/integration/ruoyi-business-ui.mjs
```

运行前端界面测试时，管理端需指向隔离服务的 5175 端口，终端需指向 5176；生产环境禁止运行这些脚本。
